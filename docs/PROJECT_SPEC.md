# プロジェクト仕様

## 概要

- 対象：株式会社ストラテジックアライアンス
- 種別：保険関連職種に特化した採用サイト
- 目的：保険募集人の採用・育成・教育・マネジメントを担う人材の採用強化
- 基準デザイン：PC 1440px

会社全体の採用サイトではなく、保険関連職種に特化します。MAS監査や経営コンサルティングを主題にしません。

## 主要コピー

### ファーストビュー

- キャッチコピー：保険の力で、人と組織を育てる仕事。
- サブコピー：保険募集人・ファイナンシャル・アドバイザーの採用、育成、マネジメントを担う仕事です。
- 職種バッジ：保険募集人 採用・育成・マネジメント担当
- CTA：エントリーする

### 採用メッセージ

> 保険募集人一人ひとりが、自分らしく力を発揮できる環境をつくること。
>
> 採用計画に基づいた人材の採用から、教育・管理・指導、そして業務品質の向上まで。  
> 「営業を支援する」だけでなく、「組織そのものを育てる」役割を担います。
>
> 保険募集人が力を発揮できれば、お客様に届く安心も大きくなる。  
> 私たちは、その循環をつくる仕事です。

### 仕事内容

- 募集人採用
- 教育・管理
- 売上・生産性
- 業務品質
- リスク管理
- 保険会社連携

## 募集要項

LPには概要を表示し、詳細ページへ誘導します。

- 募集職種
- 仕事内容
- 雇用形態
- 勤務地
- 勤務時間
- 給与
- 休日休暇
- 福利厚生
- 応募資格
- 歓迎条件

募集職種と仕事内容以外の8項目は仮情報です。確定情報が届いたら、LPと詳細ページを同時に更新します。

## エントリーフォーム

所要時間の目安は約10〜15分です。4ステップの後に確認画面を表示します。

### Step 1：基本情報

- 氏名
- フリガナ
- 生年月日
- 電話番号
- メールアドレス
- 住所
- 現在の就業状況

### Step 2：経験・スキル

- 保険業界での経験年数
- 金融業界での経験年数
- 営業経験年数
- マネジメント経験の有無
- 採用、育成、教育経験の有無
- 労務管理経験の有無
- 保険募集管理、コンプライアンス関連経験の有無

### Step 3：保有資格・職務経歴

- 生命保険募集人資格
- 損害保険募集人資格
- FP資格
- その他保有資格
- 直近の勤務先
- 経験業務
- マネジメント人数
- 主な実績
- 職務経歴書アップロード

### Step 4：自由入力

- 志望動機
- 自己PR
- 希望条件
- 質問・連絡事項

希望職種、希望勤務地、希望入社時期、希望雇用形態、応募経路は設けません。
