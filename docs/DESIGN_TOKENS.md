# デザイントークン・UIルール

## コンセプト

知的な信頼感、静かな成長感。

保険・金融領域に必要な誠実さと清潔感を土台に、余白、整列、抑えた装飾で現代的な印象を作ります。

## カラー

| 用途 | 変数名 | 値 |
| --- | --- | --- |
| Primary | `primary` | `#1C2B45` |
| Accent | `secondary` | `#B08D57` |
| Background | `background` | `#FAF9F6` |
| Surface | `surface` | `#FFFFFF` |
| Main text | `text-primary` | `#1F2328` |
| Secondary text | `text-secondary` | `#5C6470` |
| Border / Divider | `border` | `#E4E1DA` |

ゴールドはCTA、アイコン、見出しのアクセントに限定して使用します。

Figmaには「Recruit LP / Colors」コレクションとして登録済みです。実装時はSCSS変数またはCSSカスタムプロパティへ同じ役割名で定義します。

## タイポグラフィ

- フォント：Noto Sans JP
- 見出し：Bold / Medium
- 本文：Regular
- 明朝体は使用しない
- 日本語と英数字が混在しても読みやすいウェイトを選ぶ
- サイズ、行間、字間は対象Figmaノードを基準にする

フォント指定はfoundationへ集約し、コンポーネントごとに別のフォントスタックを持たせません。

## 余白

- LPセクション上下：120〜160px程度を基準
- 通常の要素間：24〜32pxを基準
- 基準幅：PC 1440px
- Figma上の主要左右余白：80px
- フォーム本体の基準幅：720px

上記は初期基準です。各セクションの正確な値はFigmaを優先します。

## UIルール

- Primary CTA：ネイビー背景＋白文字
- Accent CTA：ゴールド背景＋ネイビー文字
- Secondary button：アウトライン、またはテキストリンク＋矢印
- カード：白背景＋薄いボーダー。影は控えめにする
- フォーム：小さめの角丸＋薄いグレーの枠線
- 選択項目：用途に応じてラジオボタン、チェックボックス、セレクトを使い分ける
- 必須表示：ゴールド系の控えめなマーク
- 同じ役割の要素は、色、余白、角丸、文字スタイルを統一する

## 写真・ビジュアル

- 自然光の落ち着いたオフィスシーン
- 1人〜少人数の自然な表情
- 人材育成や対話が伝わる場面
- 握手やスーツ集合写真に偏らない
- ネイビー、白、ゴールドのブランドトーンに合わせる
- 幾何学模様、ライン、半透明の重なりを装飾として使用する

最新LP候補`36:106`には写真と装飾が反映されています。実装時は各レイヤーを個別素材として扱い、画面全体のキャプチャを背景画像にしません。

## 実装時の扱い

- 色は役割名で変数化し、ページ固有の値を増やしすぎない
- Figmaの数値を機械的にすべて固定値へ変換しない
- デザインの位置関係を保ちながら、通常フロー、Flexbox、Gridへ置き換える
- 例外的な装飾値は、理由が分かる短いコメントを残す
